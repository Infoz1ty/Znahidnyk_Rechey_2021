## Що зроблено та як працює логіка
* **Роздільні ручні операції дилатації та ерозії (`binary_dilate_manual`, `binary_erode_manual`):** оскільки квадратний структуруючий елемент $k\times k$ є роздільним, кожна операція виконується за два 1D-проходи (по X, потім по Y) через зрізи `NumPy`, що знижує складність із $O(k^2)$ до $O(2k)$.
* **Морфологічне закриття та відкриття (`morphological_close_manual`, `morphological_open_manual`):** під час закриття робоча маска тимчасово доповнюється нулями на `pad = k // 2` перед дилатацією та обрізається після ерозії — це гарантує математичну екстенсивність ($A \subseteq A \bullet B$) навіть для деталей, що торкаються межі кадру.
* **Ручний BFS flood-fill заповнення внутрішніх дірок (`fill_holes_manual`):** фонові пікселі розбиваються на горизонтальні прогони `[start, end)` по кожному рядку (`_extract_bg_runs`), у чергу `collections.deque` поміщаються всі прогони, що торкаються 4 меж кадру (`_seed_border_runs`), після чого виконується 4-зв'язний BFS по перекриттю прогонів сусідніх рядків; усі недосяжні внутрішні фонові ділянки (відблиски на шпильках) заповнюються як передній план. Повна Стадія 3 виконується за `~51 мс` на кадрі `1600×1064`.
