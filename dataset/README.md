# Пам'ятка зі збору та організації гібридного датасету (110–120 зображень)

Вибірка поєднує **40 реальних фотографій** розсипів LEGO (по 20 від кожного учасника) та **70–80 3D-рендерів** із відкритого датасету Kaggle (*LEGO brick images*, вигляд зверху $90^\circ$).

---

## 1. Структура каталогу `dataset/`

```text
dataset/
├── real_u1/             # 20 реальних PNG-фото від Учасника 1
├── real_u2/             # 20 реальних PNG-фото від Учасника 2
├── real_masks/          # 20 еталонних бінарних масок (10 від У1 + 10 від У2) для IoU
├── kaggle_topdown/      # 70–80 відібраних PNG-рендерів зверху (90°) із Kaggle
├── kaggle_masks/        # Автоматично згенеровані бінарні маски для Kaggle-вибірки
├── sample/              # 2–3 невеликі демо-фото (+ маски) для швидкого запуску за README
└── labels.csv           # Таблиця анотацій для всієї вибірки
```

| Код | Сценарій розкладки | Учасник 1 | Учасник 2 | Разом | Деталей у кадрі | Вимоги до сцени |

## 3. Технічні вимоги до зйомки (для обох учасників)

1. **Ракурс:** камера строго під $90^\circ$ до столу (використовуйте вбудований електронний рівень на телефоні/камері).
2. **Освітлення:** м'яке розсіяне (денне світло від вікна або розсіяна лампа), **спалах вимкнено**, без HDR та AI-покращень камери.
3. **Фон:** однотонний матовий світло-сірий або бежевий аркуш паперу/картону (без текстури дерева й глянцевих відблисків).
4. **Масштаб:** підберіть висоту зйомки так, щоб після зменшення довгої сторони кадру до $1600\text{ px}$ одна базова шпилька (`1x1 stud`) займала **$25\text{--}35\text{ px}$**.
5. **Формат:** 8-бітний `PNG`. Якщо знімали у RAW (`.nef` / `.dng`), сконвертуйте через `python scripts/convert_raw.py`.

---

## 4. Правила іменування файлів та формат `labels.csv`

* **Реальні фото:** `<owner>_<scenario>_<index>_n<count>.png`
  * Приклади: `u1_a_01_n7.png`, `u1_b_03_n11.png`, `u2_c_05_n16.png`.
* **Еталонні маски:** ідентичне ім'я файлу з суфіксом `_mask.png` у `real_masks/` або `kaggle_masks/` (одноканальний 8-бітний PNG: `0` — фон, `255` — деталі).
* **Формат `labels.csv`:**
  * `filename` — відносний шлях від `dataset/` (наприклад, `real_u1/u1_a_01_n7.png`);
  * `split` — `real_u1`, `real_u2` або `kaggle_topdown`;
  * `scenario` — `a`, `b`, `c` або `kaggle`;
  * `has_mask` — `true` або `false`;
  * `total_count` — загальна кількість деталей у кадрі;
  * `items_json` — JSON-масив очікуваних міток формату `["red_2x4_brick", "blue_2x2_tile", ...]`.
